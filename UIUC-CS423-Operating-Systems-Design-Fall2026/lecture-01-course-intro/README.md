## 内容要点

- 课程定位：在 CS 341 之上的操作系统设计进阶课，强调原理与真实内核实现
- 操作系统三大抽象：进程（CPU 虚拟化）、地址空间（内存虚拟化）、文件（持久化存储）
- 课程组织方式：课堂讲原理 + 5 个 Machine Problems 修改内核代码
- 阅读方法：如何高效读系统论文（C4 阅读要求的起点）
