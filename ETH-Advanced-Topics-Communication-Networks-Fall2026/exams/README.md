# Exams（历年考试）

官方考试页面提供的历年闭卷笔试试卷（180 分钟）与部分年份的解答。
下载自 `https://adv-net.ethz.ch/pdfs/`。

| 年份 | 试卷 | 解答 |
|---|---|---|
| 2021 | `exam-2021.pdf` | 官方未提供 |
| 2022（HS） | `exam-2022-hs.pdf` | 官方未提供 |
| 2022（SS） | `exam-2022-ss.pdf` | 官方未提供 |
| 2023 | `exam-2023.pdf` | 官方未提供 |
| 2024 | `exam-2024.pdf` | `sol-2024.pdf` |
| 2025 | `exam-2025.pdf` | `sol-2025.pdf` |
| 2026 | `exam-2026.pdf` | `sol-2026.pdf` |

## 说明

- 2022 年有 HS（Herbstsemester）与 SS（Sommersemester）两套试卷。
- 仅 2024、2025、2026 年提供官方解答（`sol_YYYY.pdf`）；2021、2022、2023 年官方未提供解答。
