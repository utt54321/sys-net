## 课程简介

本课程系统讲授数据通信与计算机网络的原理与实践，覆盖从物理层到应用层的完整协议栈。

课程以自顶向下的方式组织：先讨论应用层协议与编程接口，再逐层下探到传输层、网络层、链路层与物理层。

除教材内容外，课程还包含容器与容器管理、排队系统性能分析、软件定义网络、网络安全、多媒体网络与网络管理等专题。

课程包含作业、编程实验（如使用 Wireshark 进行报文分析）、期中与期末考试；实验与作业要求独立完成。

成绩构成：作业 20%、编程作业/实验 25%、出勤与课堂参与 5%、期中 20%、期末 30%。
