## 内容要点

- 数字信号与调制/编码
- 带宽、噪声与信道容量（Nyquist、Shannon）
- 传输介质：铜缆、光纤与无线
- 物理层在协议栈中的位置与接口

> 要点依据官方 Session 标题与课程教材《Computer Networking: A Top-Down Approach》对应章节归纳。
