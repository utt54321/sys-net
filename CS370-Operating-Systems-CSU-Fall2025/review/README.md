## 使用建议

1. 期中前：先看 `study-guide-midterm.pdf`，再配合 Help Session 1-3 与 `midterm-review.pdf` 复习第 1-6 章。
2. 期末前：`study-guide-ch8-18.pdf` 覆盖后半学期（内存管理、虚拟内存、文件系统、I/O、虚拟化等），
   `final-review.pdf` 为最后一讲的复习 slides。
3. 每份 Help Session 都对应一次作业或考试的答疑，建议结合对应讲次的 `slides.pdf` 一起看。
