## 内容要点

- 自动微分（AD）的定义：对程序本身求导，而非符号求导或数值差分
- 前向模式与反向模式的区别及各自复杂度
- 反向模式 AD 与反向传播的等价性：伴随（adjoint）变量与拓扑逆序
- 计算图构建、节点梯度累加、非标量输出的处理
